## Reward shaping

В этом задании используется модифицированная награда:

```python
modified_reward = reward + 300 * (
    gamma * abs(new_state[1]) - abs(state[1])
)
```

Где:

* `state[1]` — текущая скорость;
* `new_state[1]` — скорость после действия;
* `gamma` — коэффициент дисконтирования агента.

**Эта модификация награды — часть задания, её нельзя удалять или заменять.**

Награда вычисляется на каждом шаге окружения перед тем, как переход сохраняется в replay buffer.

Для данной задачи важно использовать модифицированную награду, чтобы агент мог эффективно учиться, так как оригинальная награда слишком мала, и получить её случайным образом почти невозможно. Это очень распространённая проблема в RL.

## Процесс работы над заданием

### Универсальная структура агента

Все агенты должны соответствовать универсальной структуре агента, которая указана в `src/agents/base_agent.py`.

Нужно реализовать методы:

```python
@abstractmethod
def act(self, state, training: bool = True):
    # Выбрать действие на основе текущего состояния.
    # training = True — агент находится в состоянии обучения.
    # training = False — агент находится в состоянии оценки.

@abstractmethod
def remember(self, state, action, reward, next_state, done):
    # Запомнить текущее состояние и положить его в Replay Buffer.

@abstractmethod
def learn(self):
    # Выполнить обучение и обновить веса модели.

@abstractmethod
def step_epsilon(self):
    # Выполнить шаг по уменьшению epsilon.
    # Для некоторых модификаций можно указать pass.
```

### Запуск эксперимента

В файле `main.py` в функции `make_agent` необходимо реализовать создание агента.

Например, для Rainbow DQN можно использовать следующий код:

```python
def make_agent() -> BaseDQNAgent:

    state_dim = 2

    action_dim = 3

    agent = RainbowDQNAgent(
        state_dim=state_dim,
        action_dim=action_dim
    )

    return agent
```

И запустить обучение с помощью команды:

```bash
python main.py --mode train --name rainbow_dqn
```

А затем оценить обученную модель с помощью команды:

```bash
python main.py --mode evaluate --name rainbow_dqn
```

И отрендерить эпизод с помощью команды:

```bash
python main.py --mode render --name rainbow_dqn
```
